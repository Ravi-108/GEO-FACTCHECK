Part 2 — Fact-check app (core build)

~3 hours · The main technical deliverable

Project file structure

factcheck-app/ ├── app.py ← Streamlit UI (main entry) ├── modules/ │ ├── pdf_extractor.py ← extract text from PDF │ ├── claim_finder.py ← Claude identifies claims │ ├── web_verifier.py ← Tavily searches web │ └── verdict_engine.py ← Claude gives final verdict ├── .streamlit/ │ └── secrets.toml ← API keys (never commit!) ├── requirements.txt ├── .gitignore └── README.md

Step 1 — PDF extractor (20 min)

Write pdf_extractor.py using pdfplumber to extract text page by page
import pdfplumber def extract_text(uploaded_file) -> str: text = "" with pdfplumber.open(uploaded_file) as pdf: for page in pdf.pages: text += page.extract_text() or "" return text

Step 2 — Claim finder via Claude (40 min)

Write claim_finder.py — prompt Claude to return claims as JSON list
import anthropic, json def extract_claims(text: str) -> list[dict]: client = anthropic.Anthropic() prompt = f"""Extract every verifiable factual claim from the text below. Focus on: statistics, percentages, dates, financial figures, technical specs. Return ONLY a JSON array. Example: [{{"claim": "X grew by 40% in 2023", "type": "statistic"}}] TEXT: {text[:6000]}""" msg = client.messages.create( model="claude-sonnet-4-6", max_tokens=1500, messages=[{"role":"user","content":prompt}] ) raw = msg.content[0].text return json.loads(raw)

Step 3 — Web verifier via Tavily (30 min)

Write web_verifier.py — search each claim, return top snippets
from tavily import TavilyClient def search_claim(claim: str, api_key: str) -> list[str]: client = TavilyClient(api_key=api_key) results = client.search( query=claim, search_depth="advanced", max_results=4 ) return [r["content"] for r in results.get("results", [])]

Step 4 — Verdict engine via Claude (40 min)

Write verdict_engine.py — Claude compares claim to web evidence, outputs verdict + correction
def get_verdict(claim: str, evidence: list[str], client) -> dict: evidence_text = "\n".join(evidence[:3]) prompt = f"""You are a fact-checker. Given a claim and web evidence: - VERIFIED: claim matches evidence - INACCURATE: claim is outdated or partially wrong - FALSE: no evidence supports the claim Claim: "{claim}" Evidence: {evidence_text} Return ONLY valid JSON: {{"verdict":"VERIFIED|INACCURATE|FALSE", "confidence":"HIGH|MEDIUM|LOW", "explanation":"one sentence", "correct_fact":"what the real fact is, or null"}}""" msg = client.messages.create( model="claude-sonnet-4-6", max_tokens=400, messages=[{"role":"user","content":prompt}] ) return json.loads(msg.content[0].text)

Step 5 — Streamlit UI / app.py (50 min)

Build the main UI: PDF upload, progress bar, results table with color-coded verdicts
Read API keys from st.secrets (not from user input — it's a security risk)
Add download button for the report as CSV
import streamlit as st, anthropic, pandas as pd from modules.pdf_extractor import extract_text from modules.claim_finder import extract_claims from modules.web_verifier import search_claim from modules.verdict_engine import get_verdict st.set_page_config(page_title="Fact-Check Agent", page_icon="🔍") st.title("Fact-Check Agent") uploaded = st.file_uploader("Upload a PDF", type="pdf") if uploaded and st.button("Run fact-check"): ANTHROPIC_KEY = st.secrets["ANTHROPIC_API_KEY"] TAVILY_KEY = st.secrets["TAVILY_API_KEY"] client = anthropic.Anthropic(api_key=ANTHROPIC_KEY) with st.spinner("Extracting text..."): text = extract_text(uploaded) with st.spinner("Identifying claims..."): claims = extract_claims(text) st.info(f"Found {len(claims)} claims. Verifying...") results = [] bar = st.progress(0) for i, c in enumerate(claims): evidence = search_claim(c["claim"], TAVILY_KEY) verdict = get_verdict(c["claim"], evidence, client) results.append({**c, **verdict}) bar.progress((i+1)/len(claims)) df = pd.DataFrame(results) st.dataframe(df, use_container_width=True) st.download_button("Download CSV", df.to_csv(), "report.csv")

Deploy to Streamlit Cloud

~1 hour · Mandatory — local-only gets rejected

GitHub push

Create a new public GitHub repo named factcheck-agent
Push your code (secrets.toml must be in .gitignore — verify before pushing)
Confirm repo is public and readable without login
git init git add . git commit -m "initial commit" git remote add origin https://github.com/YOUR_USER/factcheck-agent.git git push -u origin main

Streamlit Cloud deploy

Go to share.streamlit.io → New app → connect your GitHub repo
Set main file path to app.py
Add secrets via Advanced settings → Secrets (paste the contents of secrets.toml)
Click Deploy — wait 3–5 min for first build
Copy the live URL (e.g. https://yourapp.streamlit.app)

Test with a "trap document"

Create a test PDF with 2–3 intentionally wrong stats and upload it to the live app
Confirm the app flags those stats as INACCURATE or FALSE with correct evidence
Record what the app actually produces — use this for your demo video
If Streamlit Cloud fails to build, check the logs. 90% of failures are missing packages in requirements.txt or module import errors.
# requirements.txt (must be exact — no version conflicts) streamlit>=1.35.0 anthropic>=0.28.0 tavily-python>=0.3.0 pdfplumber>=0.10.0 pandas>=2.0.0
